## 4. 限制

- 这是**本地门禁**，不是远端 CI：组织没有自托管 GPU runner，GitHub 托管 runner
  无 GPU；推送后仍需人工在具备 GPU 的机器上复跑。
- 单卡、单架构（sm_86）、单驱动；不证明其他 GPU 或 CUDA 版本。
- 运行的是 Release 构建，未覆盖 Sanitizer；GPU 内存越界仍依赖 CPU 侧 ASan/UBSan
  与 kernel 侧差分测试。
- 正确性门禁不产生性能结论；TPOT/吞吐与 profiler 证据按
  `docs/performance/results/` 中带硬件与 commit 的报告单独引用。
- 固定模型哈希仅证明本次输入；更换模型或量化类型需重新生成记录。
